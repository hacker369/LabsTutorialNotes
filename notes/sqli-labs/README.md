> 深色终端风格的 Web 安全实验笔记入口。所有测试仅限本地或明确授权的教学靶场。

## 靶场简介

SQLi-Labs 用于学习 SQL 注入相关原理，包括输入上下文、报错与联合查询、布尔/时间盲注、Header/Cookie 注入、二次注入、过滤逻辑和堆叠查询等。当前拆分版覆盖原笔记中记录的 Less-1 至 Less-65；不同分支或靶场版本可能存在差异。

## 推荐学习方式

1. 在隔离的本地环境中安装靶场，并记录操作系统、PHP、数据库和 Web 服务版本。
2. 每关先记录输入、请求与响应，再分析源码中的数据流。
3. 将“观察结果”“源码证据”和“推论”分开记录。
4. 复现成功后补充根因、版本差异和安全修复建议；无法复现时保留错误信息与排查步骤。
