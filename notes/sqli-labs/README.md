# SQLi-Labs 学习索引

> 深色终端风格的 Web 安全实验笔记入口。所有测试仅限本地或明确授权的教学靶场。

## 靶场简介

SQLi-Labs 用于学习 SQL 注入相关原理，包括输入上下文、查询拼接、报错与联合查询、布尔/时间盲注、Header 注入、二次注入和过滤逻辑等。具体考点以当前使用的靶场源码和版本为准。

## 推荐学习方式

1. 先在隔离的本地环境中完成安装，并确认当前 PHP、数据库和 Web 服务版本。
2. 每关先记录输入、请求和响应，再分析源码中的数据流。
3. 复现成功后，补充根因、版本差异和安全修复建议。
4. 无法复现时记录实际环境与错误信息，不要直接把网上的 Payload 当作已验证结论。
