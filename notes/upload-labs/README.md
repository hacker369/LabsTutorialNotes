## 靶场简介

Upload-Labs 用于理解上传校验的不同层次，包括前端限制、请求 MIME、文件名处理、扩展名规则、文件内容检测、服务器解析配置和条件竞争。具体行为可能受操作系统、Web 服务、PHP 版本及靶场 fork 影响。

## 推荐学习方式

1. 先确认服务端实际收到的文件名、MIME 和请求字段。
2. 结合当前关卡源码，定位校验发生在客户端还是服务端，以及文件保存路径如何生成。
3. 记录操作系统、PHP 与 Apache/Nginx 配置造成的行为差异；不同版本的结果不要直接套用。
4. 总结防御方案：服务端白名单校验、随机化存储名、文件内容校验、上传目录禁止执行脚本，并避免直接信任客户端 MIME。

## 安全说明

建议使用隔离的虚拟机或容器开展实验。不要为了复现上传行为而默认关闭宿主机的安全防护；需要验证防护行为时，应优先配置靶场专用的隔离环境。
