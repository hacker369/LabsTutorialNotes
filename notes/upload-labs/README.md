## 靶场简介

Upload-Labs 可用于理解上传校验的不同层次，例如前端限制、请求 MIME、文件名处理、扩展名规则、文件内容检测、服务器解析配置和竞争条件。每关的具体行为可能受操作系统、Web 服务和 PHP 版本影响。

## 推荐学习方式

1. 先确认服务端实际收到的文件名、MIME 和请求字段。
2. 结合源码确认校验发生在客户端还是服务端，以及文件保存路径如何生成。
3. 记录不同操作系统、PHP 和 Apache/Nginx 配置下的行为差异。
4. 总结防御方案：服务端白名单校验、随机化存储名、文件内容校验、上传目录禁止执行脚本，并避免直接信任客户端 MIME。
