## 靶场简介

Google XSS Game 通过逐步增加的页面上下文与过滤条件，帮助学习者理解 HTML、JavaScript、DOM 和浏览器解析行为。每关应结合实际页面源码与浏览器表现分析。

## 推荐学习方式

1. 先观察输入如何进入 DOM 或脚本上下文。
2. 明确浏览器解析上下文，再解释输入为何产生当前结果。
3. 对比不同关卡的限制条件，避免只记忆单一输入样例。
4. 总结如何通过安全 DOM API、上下文编码和避免危险 HTML 注入来降低风险。
