# 实验环境搭建指南

本文提供通用的本地实验环境检查清单。各靶场的具体依赖和版本要求请以其源码、官方说明及对应笔记为准。

## 1. 首选隔离环境

推荐使用专用虚拟机、容器或可随时回滚的快照来运行故意存在漏洞的教学靶场。尽量不要将老旧运行时和易受攻击的服务暴露到公网，也不要在日常主机上为了实验而默认关闭安全防护。

## 2. 搭建前确认

- [ ] 已获取可信来源的靶场源码或镜像，并记录版本/提交号。
- [ ] 已确认靶场依赖的 PHP、数据库和 Web 服务版本。
- [ ] 已确认端口没有与本机现有服务冲突。
- [ ] 数据库只绑定到实验环境需要的接口，并使用独立实验账号。
- [ ] 上传目录、日志目录和数据卷已按实验需要配置。
- [ ] 环境默认不允许外部网络访问；确需联网时限制访问范围。
- [ ] 已准备快照或可重复部署方式，方便实验后还原。

## 3. Windows + phpStudy 等传统环境

部分旧版教学靶场依赖已经弃用的 PHP 函数或旧版服务器行为。请按具体靶场文档选择兼容版本，不要假设一个 PHP 版本能运行所有靶场。

启动后先验证首页、数据库连接和一个基础关卡。遇到错误时记录完整报错、运行时版本和相关配置，再进行针对性排查。

## 4. Docker 环境

使用容器时请先核对镜像维护者、来源、版本和启动参数。尽量固定镜像 tag 或 digest，不要盲目使用不明来源的镜像。端口优先绑定到本机回环地址，并避免将容器管理接口暴露到公网。

## 5. 实验结束

- 停止不再使用的容器或服务。
- 删除实验中创建的临时账号、数据和文件。
- 恢复虚拟机快照或重置数据库。
- 检查实验服务没有继续监听不需要的网络接口。
