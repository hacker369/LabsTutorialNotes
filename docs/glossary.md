# Web 安全实验术语表

| 术语 | 含义 |
|---|---|
| SQL Injection（SQL 注入） | 用户输入影响后端 SQL 语句结构或执行逻辑的问题 |
| XSS（跨站脚本） | 不可信输入在浏览器中被当作可执行脚本或危险标记解析的问题 |
| DOM（文档对象模型） | 浏览器将 HTML 文档表示为可操作节点树的编程接口 |
| MIME | 描述资源媒体类型的标识；客户端声明的类型不能替代服务端验证 |
| Payload（测试输入） | 用于验证某种行为的输入内容；应结合上下文和环境解释其作用 |
| Blind SQL Injection（盲注） | 无法直接读取查询结果时，利用可观察的真假或时间差推断信息的注入类型 |
| Context（上下文） | 输入在 SQL、HTML、JavaScript、URL 等语法中的具体位置 |
| Reproduction（复现） | 在已记录的环境和步骤下重复观察到同一行为 |
| Remediation（修复） | 从根因上消除漏洞并验证修复有效的措施 |

本术语表用于统一笔记表达。遇到具体版本、框架或浏览器行为时，应以对应官方文档和实验结果为准。
